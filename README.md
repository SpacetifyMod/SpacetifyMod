### Hi, this is the account behind spacetify

**spacetify** is a mod manager for the Spotify desktop client, built so your
themes and extensions never disappear after a Spotify update again.
Windows, macOS and Linux, in English and in French.

Everything lives in the [**spacetify-mod**](https://github.com/spacetify-mod) organisation:

- [**spacetify**](https://github.com/spacetify-mod/spacetify): the app, the `spacetify` command and the installers.
- [**gallery**](https://github.com/spacetify-mod/gallery): the verified gallery of themes and extensions.
